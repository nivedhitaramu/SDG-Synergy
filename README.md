# SDG Synergy

SDG Synergy is a sustainability networking platform that connects people, NGOs, and organizations based on shared United Nations Sustainable Development Goals.

## Features

- SDG-based profile matching
- User registration with email OTP verification
- Project collaboration
- SDG Explorer
- Events and volunteering opportunities
- Volunteer certificates
- NGO directory
- Multilingual support
- Admin dashboard
- AI-assisted sustainability guidance

## Tech Stack

- React
- Vite
- Tailwind CSS
- Express.js
- TypeScript
- PostgreSQL
- Drizzle ORM
- TanStack Query
