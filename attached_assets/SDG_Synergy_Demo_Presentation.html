Problem Statement

The Gap We're Solving

🧩

Fragmented Ecosystem

NGOs, businesses, and volunteers working on the same SDGs have no structured way to find each other and collaborate.

🔗

No SDG-First Matching

Existing platforms focus on networking by industry or geography — not by shared sustainability goals and values.

📊

Invisible Impact

Volunteer contributions, project outcomes, and collaboration history are siloed with no unified impact feed or certificate trail.

SDG Synergy is the first platform built ground-up around the 17 UN SDGs —
connecting people through shared purpose, AI matchmaking, and verifiable volunteer certificates.

Feature 03

AI-Powered Matchmaking

SDG Alignment Score — computed by comparing each user's 3 chosen SDGs to calculate percentage overlap

GPT-5.1 Analysis — OpenAI model writes a personalised collaboration rationale for every match pair

Organisation Type Diversity — NGO ↔ Business ↔ Individual pairings surfaced first for cross-sector reach

Location Context — matches from the same Indian city ranked higher for in-person collaboration potential

Accept / Decline Cards — swipe-style UX with running match history and conversation starters

Feature 04

SDG Impact Feed

A live activity stream that surfaces meaningful actions across the platform — not social noise, but purpose-driven milestones.

👋

User Joined

New members announce their 3 SDGs on joining, building community context.

📁

Project Created

Every new Help Wanted project appears here with its SDG tags and description.

🤝

Match Made

When two users accept each other, the match is celebrated in the public feed.

🙋

Project Joined

When a user joins a project, it logs the action with their SDG profile context.

Every feed event links back to the actor's profile, enabling one-click discovery of collaborators.
Feed renders in real-time using TanStack Query with automatic background refetching.

Feature 08

Volunteer Hub & Certificates

Volunteer Applications

Users submit volunteer applications to projects — name, skills, availability, motivation statement

All applications tracked per user with status: Pending / Approved / Rejected

Tab view switches between "My Certificates" and "My Records" in the Volunteer Hub

Certificates

Downloadable PDF certificates generated on approval — personalised with user name and SDG badges

Unique certificate ID for verification; linked to the submission record

Certificate ownership verified via certBelongsToUser() — prevents spoofing

Access Control

Admin routes protected server-side — non-admins get 403

Frontend nav only shows Admin link when session is admin

Feature 10

Notifications & Email

In-App Notification Center

Bell icon in navbar shows unread notification count

Notifications for: new match, project joined, event registration, submission approved

Mark all as read · individual dismiss · real-time badge update

Email Stack (Brevo Primary)

Brevo SMTP — 300 free emails/day, delivers to any recipient email address

Resend API — fallback if Brevo is unreachable

Gmail SMTP — secondary fallback for personal accounts

Emails sent for: OTP Verification · Submission Approved · Match Notification
Transactional emails are queued with retry logic — if Brevo fails, Resend fires automatically.

Feature 11

Persistent floating chat button visible on every page — click to expand a full chat interface

Feature 12

Dark Mode & Multilingual

🌙

Dark Mode

Full dark/light theme toggle stored in localStorage. Tailwind dark: variants applied across every component — sidebar, cards, modals, forms, badges, and buttons all switch seamlessly.

🌐

3-Language Support

Full translations for English · தமிழ் (Tamil) · हिन्दी (Hindi) across all pages and components. Language preference saved to sdg_lang in localStorage.

🇺🇸

English

Default language. Full coverage of all pages, navigation, forms, buttons, and messages.

🇮🇳

தமிழ் (Tamil)

Complete translation for all UI strings — navigation, hero text, cards, footer, certificates, and forms.

🇮🇳

हिन्दी (Hindi)

Full Hindi translation — same coverage as Tamil. Switchable at runtime with no page reload.

Architecture

Tech Stack

Frontend

Backend

Express.js TypeScript PostgreSQL Drizzle ORM express-session bcrypt OpenAI GPT-4.1 / GPT-5.1 Nodemailer Brevo SMTP Resend API

Monorepo with shared schema.ts ensuring type safety end-to-end from DB → API → UI
